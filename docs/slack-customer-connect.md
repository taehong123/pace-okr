# 내 Slack 워크스페이스에 OKRPTR 연결하기

OKRPTR는 고객마다 별도의 Slack Bot Token을 발급받아 워크스페이스별로 분리 보관한다. 다른 고객의 Slack이나 운영자의 테스트 Slack과 연결되지 않는다.

## 연결 방법

1. OKRPTR에서 연결할 워크스페이스의 Owner 또는 Admin으로 로그인한다.
2. **앱 연동 → Slack 데일리 봇 → 내 Slack 워크스페이스에 연결**을 누른다.
3. Slack 승인 화면에서 본인이 사용하는 Slack 워크스페이스를 선택한다.
4. 요청 권한을 확인하고 승인한다.
5. OKRPTR로 돌아오면 선택한 Slack 워크스페이스명과 사용자 이메일 매칭 상태를 확인한다.

고객이 Slack 개발자 화면을 열거나 훅 URL, Client ID, Client Secret을 입력할 필요는 없다.

## 연결 후 설정

- OKRPTR와 Slack 이메일이 같은 멤버는 자동으로 연결된다.
- 이메일로 연결되지 않은 멤버는 Slack에서 `/okrptr daily`를 입력하고 15분짜리 일회용 링크로 본인을 연결한다.
- 각 멤버는 개인 데일리 DM 사용 여부, 시간, 시간대를 설정한다.
- Owner/Admin은 봇이 참여한 채널 중 데일리 공유 채널을 선택하고 테스트 DM을 보낼 수 있다.

## 연결이 막히는 경우

- **Slack 관리자 승인 필요**: 회사 Slack 정책상 앱 설치 승인이 필요하다. Slack Owner/Admin에게 승인 요청 후 다시 연결한다.
- **이미 다른 OKRPTR 워크스페이스에 연결됨**: 기존 OKRPTR 워크스페이스에서 연결을 해제한 뒤 다시 시도한다.
- **권한 업데이트 필요**: OKRPTR의 **Slack 권한 업데이트**를 눌러 새 권한을 승인한다.
- **사용자 미연결**: OKRPTR와 Slack 이메일을 확인하거나 `/okrptr daily`의 일회용 연결 링크를 사용한다.

한 OKRPTR 워크스페이스에는 Slack 워크스페이스 하나만 연결된다. 연결을 해제해도 기존 데일리 기록은 보존되지만 예약 DM과 채널 전송은 중지된다.
